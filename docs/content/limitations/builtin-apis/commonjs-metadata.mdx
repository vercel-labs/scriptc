- **CommonJS metadata:** The module graph is fixed at build time.
  Cache deletion or reloading, metadata writes, `module.paths` mutation, and `require.extensions` are unsupported.
  Read-only access to `module.id`, `filename`, `path`, `paths`, `loaded`, `isPreloading`, `parent`, `children`, `require.main`, and `require.cache` lookup/enumeration compiles.
