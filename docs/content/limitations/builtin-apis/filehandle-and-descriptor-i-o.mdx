- **FileHandle and descriptor I/O:** Static reads and writes accept Buffer and Uint8Array windows, numeric positions, and UTF-8 strings.
  FileHandle reads also accept options records and allocate a buffer when omitted.
  Vector I/O, truncation, syncing, permission changes, descriptor ownership changes and timestamp updates compile.
  Bigint Stats remain unsupported; FileHandle streams and `readLines` are covered under File streams.
  Descriptor I/O accepts every ArrayBufferView and Buffer encoding when its arguments are only known at run time.
  A `readSync` position may be a bigint up to `2n ** 63n - 1n` less the read length.
  File operations complete synchronously before their callbacks or promise continuations.
  Descriptor permission changes on Windows throw `ENOSYS`.
