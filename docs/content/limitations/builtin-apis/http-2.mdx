- **HTTP/2:** Server push is not implemented: `pushStream`, `createPushResponse`, and the `'push'` event are refused.
  A client says so in its settings (`ENABLE_PUSH = 0`), so its `localSettings.enablePush` and the server's `remoteSettings.enablePush` for it are `false` where Node reports `true`.
  On the compatibility response, `'finish'` listeners run when `end()` returns rather than when the stream closes, so they run before the request's `'close'` and before an `end()` callback, and a response that never ended emits no `'finish'`.
  Trailers, `ping`, `goaway`, timeouts, `respondWithFile`, and the stream and session `state` records are refused; on a session or stream that reached untyped code they throw instead of being ignored.
