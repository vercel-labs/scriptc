`http.request()`, `http.get()`, `https.request()`, and `https.get()` accept a URL string or URL object in place of the options, with the options and callback after it.
A URL that carries a username or password throws a catchable error before anything is sent.
Node turns those credentials into a Basic `Authorization` header, and scriptc refuses the call rather than send the request unauthenticated.
Pass the header yourself instead, for example `{ headers: { Authorization: "Basic " + Buffer.from("user:pass").toString("base64") } }`.
