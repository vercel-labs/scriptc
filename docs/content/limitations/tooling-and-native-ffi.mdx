`scriptc run` prints the program's output only.
The warnings and notes of a build, such as divergence warnings and the Node island notes, appear with `scriptc build`.

Native FFI links C functions declared in a manifest.
Formats 2–5 support call-scoped callbacks, copied string/byte callback parameters, explicitly released retained callbacks, and asynchronous foreign-thread delivery.
Format 6 adds single-precision floats, signed 8-bit and signed/unsigned 16-bit integers, and borrowed writable byte spans.
Variadic calls, structs by value, owned pointer/string/byte returns, runtime dynamic-library loading, and library-mode builds are unsupported.
See [Native FFI](/docs/ffi).

Numbers follow JavaScript's double-precision semantics.
