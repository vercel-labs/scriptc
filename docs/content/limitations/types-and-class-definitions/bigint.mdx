- **BigInt:** `BigInt64Array`, `BigUint64Array`, BigInt filesystem stats are unsupported.
  Arbitrary-precision BigInts otherwise support literals, operators, conversions, arrays, records, classes, closures, unions, promises, typed Map keys and Set elements, Buffer 64-bit reads/writes, and DataView 64-bit access.
  Native `unknown` and JavaScript `any` storage preserve BigInts, including checked Map keys and Set elements.
  JSON serialization throws a `TypeError` unless a replacer converts the value.
