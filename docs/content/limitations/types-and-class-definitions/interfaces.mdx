- **Interfaces:** Interfaces explicitly implemented by compiled classes retain live object identity through checked native values.
  Method-signature interfaces and callable-property interfaces structurally implemented by class methods use the same representation.
  A call to a method signature of such an interface calls the class's method directly when the receiver is an instance of a compiled class, and a read of a property signature reads the class's field directly; object literals, accessors, and methods the program replaces on an instance or prototype use dynamic property lookup.
  Arrays of such interface values are native arrays whose elements keep their identity; methods without a native form for them run on the array's dynamic view, which shares its elements.
  Other data interfaces retain native record layouts and their copy-coercion rules.
  Generic methods require a statically resolved body; a `const` interface binding initialized directly with `new` can keep the concrete class for specialization.
  Unsupported member representations produce diagnostics.
